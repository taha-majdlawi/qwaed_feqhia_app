# القواعد الفقهية — حزمة الصوت والتفريغ

كل حلقة مربوطة بملفاتها عبر معرّف واحد ثابت: `ep01` … `ep12`.

```
qawaid-fiqhiyya/
├── episodes.json      ← الفهرس الرئيسي: كل حلقة ومسارات ملفاتها
├── audio/ep01.m4a     ← الصوت (AAC أحادي 64kbps)
├── text/ep01.txt      ← النص الكامل (UTF-8)
├── word/ep01.docx     ← نسخة Word
├── sync/ep01.json     ← النص مقسّماً إلى فقرات مع وقت بداية ونهاية كل فقرة بالثواني
└── player.html        ← مشغّل تجريبي: افتحه بالمتصفح لترى الربط عملياً
```

## episodes.json

```json
{
  "id": "ep01",
  "number": 1,
  "title": "القواعد الفقهية – الحلقة 1",
  "duration": 822.3,
  "audio": "audio/ep01.m4a",
  "text":  "text/ep01.txt",
  "word":  "word/ep01.docx",
  "sync":  "sync/ep01.json",
  "paragraphCount": 23
}
```

## sync/epXX.json

```json
{ "paragraphs": [ { "index": 1, "start": 0.0, "end": 18.0, "text": "بسم الله..." } ] }
```

في التطبيق: أثناء التشغيل ابحث عن الفقرة التي يقع فيها `currentTime` بين `start` و`end` لتمييزها، وعند الضغط على فقرة انتقل بالصوت إلى `start`.

ملاحظة: أوقات الفقرات تقريبية (دقتها في حدود ثوانٍ قليلة)، استُخرجت آلياً بمطابقة النص المراجَع مع التفريغ الأولي.
