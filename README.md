# القواعد الفقهية وتطبيقاتها — تطبيق Flutter

تطبيق للاستماع إلى سلسلة **القواعد الفقهية وتطبيقاتها** للشيخ الدكتور **عدنان بن عوض الرشيدي**
(عضو هيئة التدريس بكلية الشريعة — جامعة الكويت)، مع عرض نصّ كل حلقة متزامناً مع الصوت.

المصدر: إذاعة القرآن الكريم — دولة الكويت. عدد الحلقات: ٤٢.

---

## المزايا

| | |
|---|---|
| 🎧 **تتبّع النص مع الصوت** | تُظلَّل الفقرة الجارية تلقائياً، والشاشة تتبعها وحدها |

| ⭐ **المفضلة** | حفظ الحلقات المهمّة في مكان واحد |
| 📍 **العلامات** | حفظ لحظة معيّنة مع ملاحظة، والرجوع إليها لاحقاً |
| ⏱️ **متابعة الاستماع** | يحفظ موضعك في كل حلقة ويستأنف منه |
| ⬇️ **تحميل للاستماع دون إنترنت** | لكل حلقة على حدة أو للسلسلة كاملة |
| 🔁 **تكرار** | الحلقة كاملة أو الفقرة الواحدة (للحفظ والمراجعة) |
| 🐢 **سرعة التشغيل** | من ٠٫٧٥× إلى ٢× |
| 🌙 **مؤقّت النوم** | إيقاف بعد مدّة أو عند نهاية الحلقة |
| 🎛️ **التحكّم من الإشعار** | تشغيل في الخلفية مع أزرار التحكّم (أندرويد / iOS) |
| 🌓 **وضع داكن** وحجم خط قابل للتكبير | |

## صيغة البيانات

`episodes.json`

```json
{
  "id": "ep01",
  "number": 1,
  "title": "القواعد الفقهية – الحلقة 1",
  "duration": 822.3,
  "audio": "audio/ep01.m4a",
  "sync":  "sync/ep01.json",
  "paragraphCount": 23
}
```

`sync/epXX.json`

```json
{ "paragraphs": [ { "index": 1, "start": 0.0, "end": 18.0, "text": "بسم الله…" } ] }
```

> أوقات الفقرات تقريبية (دقّتها في حدود ثوانٍ قليلة)، استُخرجت آلياً بمطابقة النص المراجَع مع التفريغ الأولي.

## الملفات الصوتية

حجم الصوتيات ٢٥٢ ميجابايت، فلا تُرفع داخل المستودع ولا داخل حزمة التطبيق.
التطبيق يشغّلها من **GitHub Releases**، ويتيح تحميل أي حلقة إلى الجهاز للاستماع دون إنترنت.

### رفع الصوتيات (مرة واحدة)

1. أنشئ إصداراً في المستودع وسمِّ وسمه (tag) **`audio-v1`** بالضبط.
2. ارفع ملفات `audio/ep01.m4a` … `audio/ep42.m4a` كمرفقات للإصدار (بأسمائها كما هي).
3. لا شيء آخر — التطبيق يبني الرابط هكذا:

```
https://github.com/taha-majdlawi/qwaed_feqhia_app/releases/download/audio-v1/ep01.m4a
```

أسهل طريقة — سكربت جاهز في المستودع (آمن للتكرار، ويستأنف ما بقي لو انقطع الرفع):

```bash
gh auth login          # مرة واحدة فقط
bash tools/upload-audio.sh
```

وللتأكد لاحقاً أن كل حلقة متاحة بالحجم الصحيح على الرابط الذي يقرأ منه التطبيق:

```bash
bash tools/verify-audio.sh
```

لتغيير مكان الاستضافة لاحقاً، عدّل `audioBaseUrl` في [app/lib/core/constants.dart](app/lib/core/constants.dart) فقط.

## التشغيل

```bash
cd app
flutter pub get
flutter run
```

### اختبار الصوت قبل رفعه على Releases

رابط الصوت قابل للتبديل وقت البناء، فيمكن تجربته من خادم محلي:

```bash
flutter run --dart-define=AUDIO_BASE_URL=http://10.0.2.2:8100/
```

(`10.0.2.2` هو عنوان جهازك من داخل محاكي أندرويد. نسخة التصحيح تسمح بـ HTTP
عبر `android/app/src/debug/AndroidManifest.xml`، أما نسخة الإصدار فلا تسمح إلا بـ HTTPS.)

### تنبيه: مسار المشروع يجب أن يكون لاتينياً

أدوات CMake/NDK على ويندوز تفشل إن كان مسار المشروع يحتوي حروفاً عربية
(`libdartjni.so` يُبنى على مسار مشوَّه فلا يجده Gradle). لذلك مجلد `app/`
الحقيقي على جهاز المالك في `C:\qawaid-app`، و`app` داخل المستودع وصلة (junction)
تشير إليه. أي نسخة جديدة في مسار لاتيني لا تحتاج هذا الترتيب.

لبناء نسخة أندرويد:

```bash
cd app
flutter build apk --release
```

**المنصّات:** أندرويد و iOS و ويندوز.
بناء ويندوز يحتاج Visual Studio مع حزمة «Desktop development with C++».
